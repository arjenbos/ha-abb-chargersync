# Project language

- Write code, identifiers, comments, docstrings, documentation, filenames, and examples in English.
- English is the default language for integration UI strings and service descriptions.
- Put other languages only in locale-specific files under `custom_components/abb_chargersync/translations/`, such as `nl.json` for Dutch.
- Preserve external API field names, protocol identifiers, and source evidence exactly as observed; do not translate them.
- Apply this policy to new work and updates to existing files.
